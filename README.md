# The Lost Manuscript - web edition

Upload `index.html`, `.nojekyll`, and the entire `assets` folder to the same repository folder. Keep all filenames and folder names unchanged. Upload the extracted files, not the ZIP archive.

For GitHub Pages, select the branch and folder containing index.html as the publishing source under the repository Settings > Pages. Open the resulting Pages address to play.

All images, music, styles, and game code are included. The demonstration video link requires internet access. No build step is required.

For local testing, use a local web server. Keep the original standalone HTML for opening directly from disk without a server.

This edition preserves the puzzles, answers, saved-progress key, fullscreen controls, and 3 / 2 / 1 minute hint waits. Photographic illustrations use WebP compression; puzzle sheets, the encryption key, periodic table, and diagrams use lossless WebP. Audio is unchanged.
